# مِرصاد المستودع

تطبيق Expo/React Native للتابلت لإعداد جلسات تدقيق فواتير المستودع من ملفات محلية، ثم مطابقة الباركود والكميات بمساعدة قارئ خطي HID.

## التشغيل والتطوير

```bash
corepack pnpm install --prefer-offline
pnpm dev
```

معاينة الويب للتصميم والتطوير فقط. مخزنها مؤقت في الذاكرة، فلا تستخدم فواتير عملاء حقيقية فيها. يستخدم Android SQLite محلية وأرشفة داخل مساحة التطبيق الخاصة.

## فحوص المصدر

```bash
pnpm check
pnpm lint
pnpm test
pnpm exec expo export --platform android --output-dir /tmp/marsood-android
pnpm exec expo export --platform web --output-dir /tmp/marsood-web
```

اختبارات الوحدة تستخدم بيانات اصطناعية. `expo export` ينتج حزمة JavaScript/ويب ولا ينتج APK.

## الملفات والباركود

يستورد التطبيق Excel/XLSX وXLS وCSV وPDF من منتقي الجهاز. تُعاين بيانات Excel وتُربط أعمدتها؛ وتُعامل الصفوف التي بها مشكلات كأخطاء ظاهرة. يقرأ PDF النص القابل للاستخراج فقط ويعرض الصفوف المرشحة للمراجعة. **PDF المصور يحتاج OCR/نسخة نصية؛ OCR غير مضمن في هذا الإصدار.**

حقل HID يقبل Enter أو Tab، والمسح الواحد يزيد بند الفاتورة وحدة واحدة، حتى إذا تكرر الباركود في مسح لاحق. لا تُعتمد الباركودات المجهولة أو البنود الملتبسة آلياً، ولا تُقفل الجلسة قبل المطابقة وحسم الاستثناءات.

## الخصوصية والبناء الأصلي

لا يرفع التطبيق الملفات أو سجلات التدقيق ولا يستخدم خدمة خلفية في تدفق الفواتير. Package ID لهذه النسخة هو `space.manus.marsood.t173502143869505`؛ ملف WOM الأصلي هو `com.app.mywebapp`، لذا هذه حزمة منفصلة وليست تحديثاً متوافقاً معه.

لإنشاء ملف تثبيت Android، احفظ نقطة المصدر ثم استخدم إجراء **Build Android APK/AAB** الرسمي في Dashboard. يلزم تثبيته على التابلت واختبار قارئ USB/Bluetooth ونسخة SQLite ومنتقي الملفات قبل اعتماده إنتاجياً.
